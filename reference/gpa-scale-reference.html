GPA Scales Reference: 4.0, Weighted, and Percentage Equivalents

Formula Shelf Reference Desk · Definition page · Reviewed October 2026

Definition

A reference table for unweighted and weighted GPA scales and their approximate percentage equivalents.

Worked example

On the standard unweighted scale: A = 4.0 (≈93–100%), B = 3.0 (≈83–86%), C = 2.0 (≈73–76%), D = 1.0 (≈65–66%), F = 0. Weighted scales add points for advanced classes — an A in an honours class may count 4.5 or 5.0 — which is why a weighted GPA can exceed 4.0 and why the two kinds must never be compared directly.

Read this before using it

Percentage equivalents vary by school and country; the ranges here are the commonly used US bands. Always read a GPA alongside the scale printed on the transcript.
