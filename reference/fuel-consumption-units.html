Fuel Consumption Units: MPG, L/100 km, and km/L Converted

Formula Shelf Reference Desk · Definition page · Reviewed October 2026

Definition

How the three common fuel-economy units relate, exact conversion formulas, and a reference table.

L/100 km = 235.21 ÷ MPG (US) · km/L = MPG (US) × 0.4251 · MPG (US) = 282.48 ÷ L/100 km (for UK gallons use 282.48 in place of 235.21 where noted)

Worked example

MPG and km/L rise when a car is efficient; L/100 km falls. That opposite direction is the main source of conversion mistakes — always check which way the number should move.

Read this before using it

US and UK gallons differ (1 UK gallon ≈ 1.201 US gallons), so a UK MPG figure is higher than the same car's US MPG figure. Confirm which gallon a source uses before comparing.
